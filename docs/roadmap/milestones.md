# Milestones

## M1 - Offline Assets Editor for 15.x

Status: `in progress`

Exit criteria:

- The current editor supports browsing, previewing, supported appearance
  properties, prepared-PNG import, and safe work-copy export.
- Pending edits have clear save, discard, and cancel behavior.
- The editor passes client-only interaction checks and a human-visible review.
- A follow-up task defines and implements safe editing through a configured
  external desktop image editor.
