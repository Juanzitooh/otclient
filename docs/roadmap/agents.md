# Roadmap guide

Read the repository root `AGENTS.md`, then `status.md`, `roadmap.md`,
`milestones.md`, and the relevant entry in `tasks.md` before roadmap work.
Record durable technical choices in `decisions.md` and keep this folder aligned
with the existing feature guide at `docs/offline-sprite-editor.md`.

for task structure and state updates. Keep the current editor scope restricted
to modern client assets 15.x.
